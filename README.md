# Tuki Tuki - Venezuelan Rhythm Game

¡Bienvenidos a Tuki Tuki! A DDR-style rhythm game celebrating Venezuelan Tuki music and culture.

## 🇻🇪 About the Game

Tuki Tuki is inspired by the Venezuelan music genre "Tuki" - a high-energy electronic music style that emerged from the barrios of Caracas in the late 1990s. This game brings the authentic spirit of Venezuelan street culture to a rhythm gaming experience.

### Features

- **Multiplayer Support**: Two players can compete side by side
  - Player 1: WASD keys
  - Player 2: Arrow keys
- **Story Mode**: Learn about Venezuelan culture and Tuki music
- **Multiple Difficulty Levels**: From beginner to challenge
- **3D Graphics**: Immersive ThreeJS-powered visuals
- **Cultural Authenticity**: Real Venezuelan themes, characters, and music styles

### Venezuelan Tuki Styles

1. **Tuki Clásico** - The original barrio sound (120-140 BPM)
2. **Tuki Rápido** - High-energy industrial beats (160-200 BPM)  
3. **Tuki Suave** - Melodic and flowing (100-130 BPM)
4. **Tuki Fusion** - Modern blend with traditional Venezuelan music (140-180 BPM)

### Characters

- **María La Caraqueña** - From Petare, Caracas
- **Carlos El Zuliano** - From Maracaibo, Zulia  
- **Lucía La Valenciana** - From Valencia, Carabobo
- **Rodríguez El Llanero** - From Barquisimeto, Lara

## 🎮 How to Play

1. **Story Mode**: Experience the cultural journey through Venezuela
2. **Multiplayer**: Challenge a friend in head-to-head rhythm battles
3. **Practice Mode**: Perfect your skills on individual songs

### Controls

**Player 1 (WASD):**
- W: Up arrow
- A: Left arrow  
- S: Down arrow
- D: Right arrow

**Player 2 (Arrow Keys):**
- ↑: Up arrow
- ←: Left arrow
- ↓: Down arrow  
- →: Right arrow

**Additional Controls:**
- ESC: Pause/Resume
- F1: Settings

## 🛠️ Development

Built with:
- React 18 + TypeScript
- ThreeJS + React Three Fiber
- Zustand for state management
- Framer Motion for animations
- Vite for development

### Getting Started

```bash

npm run dev
```
